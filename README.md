# Animal Shelter Management System (C++)

This project is a simple animal shelter management system developed using object-oriented programming in C++.

## Features
- Animal record management
- Adoption and return operations
- Role-based structure (Adopter, Staff)
- Use of inheritance and polymorphism

## Technologies
- C++
- Object-Oriented Programming
- STL (vector)

## How to Run
Compile and run ShelterSystem.cpp using a C++ compiler.
